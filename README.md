# tango

A personal Japanese vocabulary flashcard app

## Features
- Randomized flashcard sessions
- Swipe to mark words remembered or missed
- Review missed words in repeat rounds
- Vocabulary stored in JSON, sorted by Japanese reading (五十音順)

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Python Flask on Azure Container Apps
- Hosting: Azure Static Web Apps
- Vocabulary storage: GitHub JSON
